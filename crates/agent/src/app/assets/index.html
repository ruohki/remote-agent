Install as a system service

Install Remote Support as a system service to enable unattended support for this computer.

  • Starts automatically at sign-in and runs in the background
  • Every session is indicated on screen and listed in this window

Restrict what a support technician may do on this computer. Restrictions can only be stricter than the administrator policy, and apply immediately, including during an active session.
